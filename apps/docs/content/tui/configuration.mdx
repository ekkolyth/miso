# Configuration

### `tui`

Controls how concurrent scripts are displayed.

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    config={`"tui": "off" | "tabbed" | "merged"`}
/>

<DocProp prop='"off"' /> <Badge variant="default" className="bg-primary-900 font-bold text-primary-400 border-primary-400">Default</Badge>

No TUI. Normal single-process execution.

<DocProp prop='"tabbed"' />

Sidebar with workspace list, selected workspace's logs on the right. See [Tabbed Mode](/tui/tabbed-mode).

<DocProp prop='"merged"' />

Interleaved log stream with colored labels and filter toggles. See [Merged Mode](/tui/merged-mode).

You can also use the object form for additional options:

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    config={`{
  "tui": {
    "mode": "tabbed",
    "cleanExit": true
  }
}`}
/>

<DocProp prop="mode" />

TUI display mode. Accepts `"off"`, `"tabbed"`, or `"merged"`.

<DocProp prop="cleanExit" />

When `true`, suppresses the log dump on TUI exit. By default, all buffered output is printed to stdout when the TUI exits.

### `repo`

Controls how miso discovers and orchestrates workspaces.

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    config={`"repo": "single" | "mono" | "turbo" | "nx"`}
/>

<DocProp prop='"single"' /> <Badge variant="default" className="bg-primary-900 font-bold text-primary-400 border-primary-400">Default</Badge>

Standard project. Uses `concurrent` in task config for companion scripts.

<DocProp prop='"mono"' />

Monorepo. Miso discovers workspaces and orchestrates scripts directly.

<DocProp prop='"turbo"' />

Monorepo. Delegates orchestration to Turborepo — miso provides the UI. `turbo` must be available in your PATH.

<DocProp prop='"nx"' />

Monorepo. Delegates orchestration to Nx — miso provides the UI. `nx` must be available in your PATH.

You can also use the object form to configure per-task behaviour:

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    config={`{
  "repo": {
    "mode": "mono",
    "tasks": {
      "build": {
        "dependsOn": ["^build"]
      },
      "dev": {
        "concurrent": ["services", "db:studio"]
      }
    }
  }
}`}
/>

<DocProp prop="dependsOn" />

Array of task names to run before this one. The `^` prefix (e.g. `"^build"`) means run the task in upstream workspace dependencies first, reading the dependency graph from each workspace's `package.json`.

<DocProp prop="concurrent" />

Array of additional task names to discover and run in parallel alongside the main task. In turbo/nx mode, tasks listed here use miso's direct orchestration instead of delegation.

Commands not listed in `tasks`, or listed without `dependsOn`, run all workspaces in parallel.

## Script Discovery

### Monorepos

When `repo` is `"mono"`, `"turbo"`, or `"nx"`, miso auto-discovers scripts across all workspaces:

1. Reads workspace globs from root `package.json`
2. For each workspace, finds matching scripts in both the scripts folder and `package.json`
3. Prefix matching: `miso dev` matches `dev`, `dev:convex`, `dev:worker`, etc.

### Single Repos

Uses the `concurrent` config in `repo.tasks` to determine which companion scripts to run alongside the main task. Scripts are resolved through the scripts folder first, then `package.json`.

If no `concurrent` entry exists for the command, the script runs normally without the TUI.
