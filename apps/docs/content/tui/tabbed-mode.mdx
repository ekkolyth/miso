# Tabbed Mode

Tabbed mode shows a narrow sidebar on the left with your workspace/script list and a log panel on the right showing the selected workspace's output.

## Keybindings

| Key       | Action                                                        |
| --------- | ------------------------------------------------------------- |
| `↑` / `↓` | Navigate workspace list                                       |
| `r`       | Restart selected workspace                                    |
| `R`       | Restart all workspaces                                        |
| `i`       | Enter interactive mode — forward keys to the selected process |
| `Ctrl+Z`  | Exit interactive mode                                         |
| `c`       | Copy selected text to clipboard                               |
| `C`       | Copy full log buffer to clipboard                             |
| `Ctrl+C`  | Quit (stops all processes)                                    |

You can also click a workspace in the sidebar to switch to it, and click `[⎘ copy all]` in the header to copy the full log buffer.

In delegated mode (Turbo/Nx), `r` is disabled — only `R` (restart all) is available.

Press `i` to enter **interactive mode**: every keystroke is forwarded to the selected process's stdin — press `r` to reload Metro, and so on. Press `Ctrl+Z` to return to miso's controls. Interactive mode is unavailable in delegated mode (Turbo/Nx).

Hold a modifier (⌘/Alt/Ctrl) while clicking to let your terminal handle the click natively — miso ignores modifier-held clicks so opening links and native text selection keep working.

## Status Indicators

- Green `●` — process is running
- Green `✓` — process completed successfully (exit 0)
- Grey `■` — process exited 0 suspiciously fast (may have crashed without a proper error code)
- Red `✕` with exit code — process crashed
