# Flags

### Overview

The `flags` field in `miso.json` allows you to configure default flags for core package manager commands. Flags from the configuration are prepended to command-line arguments, enabling CLI arguments to override when needed.

## Configuration

Add a `flags` object to your `miso.json`:

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    config={`{
    "flags": {
        "add": ["--save-dev"],
        "remove": ["--recursive"],
        "install": ["--frozen-lockfile"],
        "dev": ["--host"]
    }
}`}
/>

## Examples

### Add

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    config={`{
    "flags": {
        "add": ["--save-dev"]
    }
}`}
/>

**Usage:**
```sh
miso add react
# Executes: pnpm add --save-dev react

miso add react --peer
# Executes: pnpm add --save-dev react --peer
```

### Install

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    config={`{
    "flags": {
        "install": ["--frozen-lockfile"]
    }
}`}
/>

**Usage:**
```bash
miso install
# Executes: pnpm install --frozen-lockfile

miso install --no-frozen-lockfile
# Executes: pnpm install --frozen-lockfile --no-frozen-lockfile
```
