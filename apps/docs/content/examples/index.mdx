# Example Configurations

Complete `miso.json` examples for common project setups.

- [**Single Repo**](/examples/single-repo) — A standard single-project setup with TUI, env validation, and flags
- [**Monorepo**](/examples/monorepo) — A multi-workspace setup with dependency ordering, concurrent tasks, and per-app env validation
- [**Simple Mode**](/examples/simple-mode) — A package-manager-free setup for non-JavaScript projects using miso as a pure script runner
