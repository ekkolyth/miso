# Basic Commands

Miso comes with a handful of built-in commands to ensure that your experience moving between package managers is perfect.

<Callout type="info">
In [simple mode](/working-with-miso/simple-mode) (`"packageManager": false`), there are no built-in commands — everything resolves as a script. The commands below (install, add, remove, dev) are only available when a package manager is configured.
</Callout>


### Install Dependencies

Install all dependencies from your lockfile:

```bash
miso install

# or

miso i
```

### Add Packages

Add one or more packages to your project:

```bash
miso add @tailwindcss
```

Flags are passed through to your package manager, exactly as you would expect:

```bash
miso add -D vitest    # dev dependency
miso add -E lodash    # exact version
```

### Remove Packages

Remove one or more packages:

```bash
miso remove lodash
```

_or_

```bash
miso rm lodash react redux
```

### Dev

Shortcut for running the `dev` script:

```bash
miso dev
```

This is equivalent to `npm run dev`/`bun dev` but also supports [flag configuration](/scripting/flags).

### Scripts

List all available scripts miso can run from both the configured scripts folder and package.json:

```bash
miso scripts
```

Output:

```
available scripts

scripts folder:
  build (build/index.sh)
  publish/patch (publish/patch.sh)

package.json:
  dev: vite dev
  lint: eslint .
```

### Env

Validate environment variables from your .env file:

```bash
miso env
```

See [Env Validation](/env-validation) for configuration and types.

### Version

Show miso version:

```bash
miso version
# or
miso v
```

Output:

```
miso 1.2.3
```

### Upgrade

Upgrade miso to the latest version:

```bash
miso upgrade
```

To upgrade miso as a local dependency instead of globally, add the `--local` flag:

```bash
miso upgrade --local
```

### misox

`misox` is a stand-in replacement for `npx`. It's a separate binary installed alongside `miso` — run it directly, not as a `miso` subcommand.

```bash
misox prettier --write .
misox eslint --init
```
