# Basic Commands

Miso comes with a handful of built-in commands to ensure that your experience moving between package managers is perfect.

<Callout type="info">
In [simple mode](/working-with-miso/simple-mode) (`"packageManager": false`), the package-management commands below (`install`, `add`, `remove`, `run`, `dev`) are unavailable and `package.json` is ignored. Miso's utility commands still work — `help`, `init`, `version`, `upgrade`, `completion`, `skills`, `env`, and `scripts` — and any other argument resolves as a script.
</Callout>


### Help

Print the full list of built-in commands. Works from anywhere — a project is not required.

```bash
miso help

# equivalent
miso --help
miso -h

# bare `miso` prints the same screen
miso
```

The output shows miso's logo, then two groups — package-management commands (`install`, `add`, `remove`, `run`, `dev`, `scripts`, `env`) and miso's own commands (`init`, `upgrade`, `skills`, `completion`, `version`, `help`) — followed by a link to these docs.

### Install Dependencies

Install all dependencies from your lockfile:

```bash
miso install

# or

miso i
```

### Add Packages

Add one or more packages to your project:

```bash
miso add @tailwindcss
```

Flags are passed through to your package manager, exactly as you would expect:

```bash
miso add -D vitest    # dev dependency
miso add -E lodash    # exact version
```

### Remove Packages

Remove one or more packages:

```bash
miso remove lodash
```

_or_

```bash
miso rm lodash react redux
```

### Dev

Shortcut for running the `dev` script:

```bash
miso dev
```

This is equivalent to `npm run dev`/`bun dev` but also supports [flag configuration](/scripting/flags).

### Scripts

List all available scripts miso can run from both the configured scripts folder and package.json:

```bash
miso scripts
```

Output:

```
available scripts

scripts folder:
  build (build/index.sh)
  publish/patch (publish/patch.sh)

package.json:
  dev: vite dev
  lint: eslint .
```

### Env

Validate environment variables from your .env file:

```bash
miso env
```

See [Env Validation](/env-validation) for configuration and types.

### Version

Show miso version:

```bash
miso version
# or
miso v
```

Output:

```
1.2.3
```

### Upgrade

Upgrade miso to the latest version:

```bash
miso upgrade
```

To upgrade miso as a local dependency instead of globally, add the `--local` flag:

```bash
miso upgrade --local
```

### misox

`misox` is a stand-in replacement for `npx`. It's a separate binary installed alongside `miso` — run it directly, not as a `miso` subcommand.

```bash
misox prettier --write .
misox eslint --init
```
