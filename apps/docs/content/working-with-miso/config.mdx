# Configuring Miso

You can edit `miso.json` directly to change its settings:

### Package Manager

Controls whether miso operates as a package manager wrapper or a standalone script runner:

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    command='"packageManager": false'
/>

<DocProp prop="boolean" /> <Badge variant="default" className="bg-primary-900 font-bold text-primary-400 border-primary-400">Default: true</Badge>

When set to `false`, miso runs in **simple mode** — all package manager features are disabled. Every command resolves as a folder script. See [Simple Mode](/working-with-miso/simple-mode) for details.

When `true` (or omitted), miso operates normally as a package manager wrapper.

### Scripts

Sets the path to the folder you want miso to use when you run custom scripts:

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    command='scripts: "./scripts"'
/>

<DocProp prop="string" />

This path is relative to the location of your miso.json file.

Learn more about [Scripting in Miso](/scripting)

### Shell

Default interpreter for scripts with no shebang and no recognized extension. If not set, Miso uses `sh`:

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    config={`"shell": "sh" | "zsh" | "bash" | "dash" | "ksh" | "fish" | "nu" | "pwsh"`}
/>

<DocProp prop="string" /> <Badge variant="default" className="bg-primary-900 font-bold text-primary-400 border-primary-400">Default: "sh"</Badge>

The selected interpreter must be available in your PATH.

### Repo

Configure how miso orchestrates task execution:

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    config={`"repo": "miso" | "turbo" | "nx"`}
/>

<DocProp prop='"miso"' /> <Badge variant="default" className="bg-primary-900 font-bold text-primary-400 border-primary-400">Default</Badge>

Miso orchestrates directly. Workspace membership is auto-detected — independent of this setting — from a `pnpm-workspace.yaml` (checked first), otherwise a `workspaces` field in your root `package.json`. When members are found, miso fans out workspace-scoped script execution using the `@workspace/script` syntax and automatic CWD-based scoping; when none are found, it runs as a single project against the root `scripts/` folder.

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="package.json"
    config={`{
    "workspaces": [
        "apps/*",
        "packages/*"
    ]
}`}
/>

See [Monorepos](/scripting/monorepos) for full details on workspace discovery and script execution.

<DocProp prop='"turbo"' />

Delegates orchestration to [Turborepo](https://turbo.build). Turbo must be installed and available in your PATH.

<DocProp prop='"nx"' />

Delegates orchestration to [Nx](https://nx.dev). Nx must be installed and available in your PATH.


### TUI

Configure the multi-terminal UI mode for running scripts across workspaces:

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    config={`"tui": "off" | "tabbed" | "merged"`}
/>

See [TUI Configuration](/tui/configuration) for the full reference.

### Flags

Add default flags to package manager commands:

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    config={`{
  "flags": {
    "install": ["--frozen-lockfile"],
    "add": ["--dev"],
    "dev": ["--env"]
  }
}`}
/>

See [Flags](/scripting/flags) for the full reference.

### Env

Configure environment variable loading and validation:

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    config={`{
  "env": [
    {
      "scope": "global",
      "label": "web",
      "path": ".env.local",
      "required": "all",
      "variables": {
        "PORT": "port",
        "DATABASE_URL": "url"
      }
    }
  ]
}`}
/>

See [Env Configuration](/env-validation/config) for the full reference.
