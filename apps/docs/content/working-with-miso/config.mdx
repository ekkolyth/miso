# Configuring Miso

You can edit `miso.json` directly to change it's settings:

### Package Manager

Set or update your project's package manager:

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    command='packageManager: "bun"'
/>

<DocProp prop="bun" />

Sets "package manager" to "bun"

<DocProp prop="pnpm" />

Sets "package manager" to "pnpm"

<DocProp prop="yarn" />

Sets "package manager" to "yarn"

<DocProp prop="npm" />

Sets "package manager" to "npm"

### Package Manager

Set or update your project's package manager:

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    command='project-name: "my-cool-react-app"'
/>

<DocProp prop="string" />

### Scripts

Sets the path to the folder you want miso to use when you run custom scripts:

<Terminal
    copy={false}
    className="mt-4 border border-neutral-700 rounded-sm"
    title="miso.json"
    command='scripts: "./scripts"'
/>

<DocProp prop="string" />

This path is relative to the location of your miso.json file. Learn more about [Scripting in Miso](/scripting)
