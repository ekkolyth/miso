Manages miso's AI agent skills for your coding harness.

### When to use

To install or remove the miso skill set for an agent harness (Claude Code, OpenCode, Codex, Gemini CLI, Cursor, Zed).

### How it works

Detects installed harnesses on your PATH and, with `--add` or `--rm`, installs or removes the skills for the chosen harness(es) in the current project. `--global` installs or removes them in your home directory instead, so every project gets them. `--yes` selects every detected harness non-interactively.

### Examples

```bash
miso skills --add
miso skills --rm
miso skills --add --yes
miso skills --add --global
miso skills --rm -g
```

### Flags

- `--add` — install the miso skills.
- `--rm` — remove the miso skills.
- `--yes` — apply to every detected harness without prompting.
- `--global` / `-g` — install or remove in your home directory instead of the current project.

### Gotchas

- `--add` and `--rm` are mutually exclusive.
- With neither flag, `skills` falls through to normal routing.
- `--rm` without `--global` removes only the project install, and `--rm --global` removes only the home-directory install.
