Prints a log message from a script, styled the way miso styles its own output.

### When to use

Inside a script, when a message should stand out from ordinary output — a missing dependency, a warning, the step that's starting.

### How it works

Takes a level (`debug`, `info`, `warn`, or `error`), the message text, and any number of `key=value` fields. When the script runs under miso, miso renders the message in the script's output. When the script runs on its own, `miso log` prints the styled message to stderr itself. It always exits 0 for a valid call; the script's own exit code decides whether it failed. Runs before any project is loaded.

### Examples

```bash
miso log info "Booting VM"
miso log error "limactl was not found" install="brew install lima"
```
